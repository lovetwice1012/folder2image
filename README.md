# FolderCodec

A command-line tool to encode and decode folders into PNG images using palette-based bit mapping, optional AES-GCM encryption, and Zfec-based erasure coding for fault tolerance.

## Features

- **Encode** a directory (including subdirectories and files) into one or more PNG images.
- **Decode** images back into the original folder structure, with optional integrity checks.
- **Optional AES-GCM encryption** with a password for confidentiality.
- **Erasure coding** using Zfec (default 30% redundancy, up to 95%) for resilience against data loss.
- **Concurrent processing**: separate pools for CPU-intensive tasks and I/O operations.
- **Low-memory mode** to reduce RAM usage.

## Requirements

- Python 3.6 or newer
- [NumPy](https://pypi.org/project/numpy/)
- [Pillow](https://pypi.org/project/Pillow/)
- [cryptography](https://pypi.org/project/cryptography/) (for AES-GCM encryption)
- [zfec](https://pypi.org/project/zfec/) (for erasure coding)

Install all dependencies:

```bash
pip install numpy pillow cryptography zfec
```

## Usage

```bash
python3 ./convert.py <command> [options]
```

### Encode a folder

```bash
python3 ./convert.py encode <folder_path> [--lowmem] [--mem MEM] [--password PASSWORD] [--compress LEVEL] [--fec_rate RATE] [--fec_rate_MAX RATE]
```

- `<folder_path>`: Path to the folder you want to encode.
- `--lowmem`: Enable low-memory mode.
- `--mem MEM`: Memory limit in bytes (default: 8 GiB).
- `--password PASSWORD`: Encrypt the payload with AES-GCM using this password.
- `--compress LEVEL`: PNG compression level (0–9, default: 1).
- `--fec_rate RATE`: Fraction of redundancy for erasure coding (0.0–0.95, default: 0.30).
- `--fec_rate_MAX RATE`: Maximum allowed erasure coding rate (default: 0.95).

The script will output files named `<prefix>_001.png`, `<prefix>_002.png`, …, and `<prefix>_file_hashes.txt` for later verification.

### Decode images

```bash
python3 ./convert.py decode <images_folder> [out_folder] [--lowmem] [--mem MEM] [--password PASSWORD] [--skip-verify] [--fec_rate RATE]
```

- `<images_folder>`: Directory containing the PNG images generated by encode.
- `[out_folder]`: Destination directory for reconstructed files (default: `outputs/YYYY_MM_DD_HH_MM`).
- `--skip-verify`: Skip SHA-256 hash verification of reconstructed files.
- Other options are the same as for encode.

## How It Works

1. **Scanning**: Recursively traverse the input folder, recording directory entries (`D`) and file entries (`F`) with base64-encoded paths and file contents.
2. **Manifest**: Save a `*_file_hashes.txt` listing each file and its SHA-256 hash for later integrity checks.
3. **Payload Preparation**:
   - Concatenate entries into a single byte stream.
   - If a password is provided, encrypt the stream using AES-GCM.
4. **Bit Mapping**:
   - Convert the byte stream to bits, then to 2-bit codes (00→black, 01→red, 10→green, 11→blue).
   - Pad codes to fill blocks sized by `width × height`. Block 0’s first pixel flags encryption.
5. **Image Generation**:
   - Map codes to RGB pixels via a lookup table.
   - Save each block as a PNG image using concurrent processing.
6. **Decoding**:
   - Read images, extract the flag, reverse the mapping to bits, and reconstruct the byte stream.
   - Decrypt if necessary and split entries to recreate directories and files.
   - Optionally verify file integrity against the manifest.

# FolderCodec（日本語）

PNG 画像へのパレットベースのビットマッピング、AES-GCM 暗号化（任意）、および Zfec ベースの冗長化を使用して、フォルダのエンコードとデコードを行うコマンドラインツール。

## 機能

- **エンコード**：ディレクトリ（サブディレクトリやファイルを含む）を 1 枚以上の PNG 画像に変換。
- **デコード**：生成された画像を元のフォルダ構造に復元（整合性チェックは任意）。
- **AES-GCM 暗号化**：パスワードを使った機密性の確保。
- **冗長化（エラー訂正符号化）**：Zfec によるデータ消失耐性（デフォルト 30% 冗長、最大 95%）。
- **並列処理**：CPU 集約タスクと I/O 操作のための別々のワーカープール。
- **低メモリモード**：RAM 使用量を削減。

## 要件

- Python 3.6 以上
- [NumPy](https://pypi.org/project/numpy/)
- [Pillow](https://pypi.org/project/Pillow/)
- [cryptography](https://pypi.org/project/cryptography/)（AES-GCM 暗号化用）
- [zfec](https://pypi.org/project/zfec/)（冗長化用）

依存関係のインストール：

```bash
pip install numpy pillow cryptography zfec
```

## インストール

## 使い方

```bash
python3 ./convert.py <command> [options]
```

### フォルダのエンコード

```bash
python3 ./convert.py encode <folder_path> [--lowmem] [--mem MEM] [--password PASSWORD] [--compress LEVEL] [--fec_rate RATE] [--fec_rate_MAX RATE]
```

- `<folder_path>`：エンコード対象のフォルダパス。
- `--lowmem`：低メモリモードを有効化。
- `--mem MEM`：メモリ上限（バイト単位、デフォルト 8 GiB）。
- `--password PASSWORD`：AES-GCM で暗号化するパスワード。
- `--compress LEVEL`：PNG 圧縮レベル（0–9、デフォルト 1）。
- `--fec_rate RATE`：冗長化符号化の冗長率（0.0–0.95、デフォルト 0.30）。
- `--fec_rate_MAX RATE`：最大冗長率（デフォルト 0.95）。

出力ファイルは `<prefix>_001.png`, `<prefix>_002.png`, …, `<prefix>_file_hashes.txt` となります。

### 画像のデコード

```bash
python3 ./convert.py decode <images_folder> [out_folder] [--lowmem] [--mem MEM] [--password PASSWORD] [--skip-verify] [--fec_rate RATE]
```

- `<images_folder>`：エンコードで生成された PNG 画像を格納したフォルダ。
- `[out_folder]`：復元先フォルダ（デフォルト `outputs/YYYY_MM_DD_HH_MM`）。
- `--skip-verify`：SHA-256 ハッシュ検証をスキップ。
- 他のオプションはエンコード時と同様。

## 動作概要

1. **スキャン**：入力フォルダを再帰的に走査し、ディレクトリエントリ（`D`）とファイルエントリ（`F`）を base64 エンコードしたパスと内容で記録。
2. **マニフェスト作成**：各ファイルとその SHA-256 ハッシュを `*_file_hashes.txt` に保存。
3. **ペイロード準備**：
   - エントリを連結してバイトストリームを生成。
   - パスワードが指定された場合、AES-GCM で暗号化。
4. **ビットマッピング**：
   - バイトストリームをビットに変換後、2 ビットずつコード化（00→黒、01→赤、10→緑、11→青）。
   - `width × height` サイズのブロックにパディング。ブロック0の最初のピクセルで暗号化フラグを示す。
5. **画像生成**：
   - コードを RGB ピクセルにマッピング。
   - 並列処理で各ブロックを PNG 画像として保存。
6. **デコード**：
   - 画像を読み込み、フラグを取得後、ピクセルからビットを復元しバイトストリームを再構築。
   - 必要に応じて復号し、エントリを分割してディレクトリとファイルを再生成。
   - マニフェストと照合して整合性検証（任意）。
